

# EV Charging Performance Analyzer

An interactive dashboard for analyzing electric vehicle (EV) charging performance, demand, session duration, usage patterns, and location trends using Python, Pandas, Plotly, and Streamlit.

## 📌 Project Overview

The **EV Charging Performance Analyzer** is a data analytics project developed as part of the **Invoqe Data Analytics Internship**.

The project explores EV charging transaction data to identify charging behavior, demand patterns, session durations, and location-level performance. An interactive Streamlit dashboard allows users to filter the data and explore key metrics through visualizations.

## 🎯 Objectives

- Analyze EV charging transaction data.
- Identify charging demand and usage patterns.
- Examine charging session duration.
- Compare charging activity across locations.
- Explore charging trends by hour, day, and date.
- Present insights through an interactive dashboard.

## ✨ Features

- Interactive dashboard built with Streamlit.
- Filters for available dataset fields, such as date, location, charger company, and charger type.
- Key performance indicators:
  - Total charging sessions
  - Unique users
  - Unique chargers
  - Average session duration
  - Average charging demand
- Charging activity trend analysis.
- Hourly and weekday usage analysis.
- Location performance comparison.
- Demand and session-duration distributions.
- Charger-type analysis.
- Filtered data table.
- CSV download for filtered results.

## 📊 Dataset

The project uses EV charging transaction data.

**Dataset source:**  
[IEEE PES Data Sharing — EV Charging Transactions](https://ieee-pes-data-sharing.org/datasets/detail/c903145b-3ba7-4fd3-ac1b-7727abf79e73)

**Related research paper:**  
[Scientific Data — EV Charging Transactions](https://www.nature.com/articles/s41597-024-02942-9)

The dataset includes transaction information such as user, charger, location, charger company, start and end times, session duration, and demand.

> Dataset units and category meanings should be interpreted according to the original dataset documentation.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Invoqe_EV_Charging_Performance_Analyzer.git
```

### 2. Open the project folder

```bash
cd Invoqe_EV_Charging_Performance_Analyzer
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, run:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
python -m pip install -r requirements.txt
```

## ▶️ Run the Dashboard

Ensure that `data/ev_charging_cleaned.csv` is available in the project folder.

Run:

```bash
python -m streamlit run app.py
```

Streamlit will provide a local URL, usually:

```text
http://localhost:8501
```

Open the URL in your browser to explore the dashboard.
